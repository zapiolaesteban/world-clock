# Archive

`world-clock-v1-original.html` is the **original World Clock** that was live at
`https://zapiolaesteban.github.io/world-clock/` until 2026-06-17.

It is kept here untouched (byte-for-byte, md5 `0cba8f78fc5567efa0343dfe4c74b740`) as a
safety net. The current live version (root `index.html`) is the enhanced build:
persistence, system-theme + reduced-motion accessibility, installable PWA manifest,
favicon/OG meta, and a native Share button — same look and logic otherwise.

To roll back: copy `archive/world-clock-v1-original.html` back to `/index.html`
(or `git revert` the promotion commit). Full history is also in git.
